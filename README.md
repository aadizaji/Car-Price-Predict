# 🚗 Car Price Prediction

## 📌 Project Overview

This project is a **Machine Learning-based Car Price Prediction System** developed using the **Linear Regression** algorithm and following the **CRISP-DM methodology**.

The main goal is to estimate the prices of **Peugeot 206, Peugeot 207, Kia Optima (K5), and Kia Sportage** based on features such as brand, model, manufacturing year, mileage, color, and gearbox type.

The project uses **Pandas and NumPy** for data processing and cleaning, **Scikit-learn** for feature encoding and model training, and **Streamlit** to create a modern, interactive, and user-friendly web interface.

Users can select their preferred car, enter its specifications, and receive an estimated price in Iranian Toman.

## 🛠 Technologies Used

- **Python**
- **Pandas & NumPy**
- **Matplotlib & Seaborn**
- **Scikit-learn (Linear Regression)**
- **One-Hot Encoding**
- **Streamlit**
- **Joblib**

## ⚠️ Disclaimer

The predicted prices are estimates generated by a machine learning model and may differ from actual market prices.
